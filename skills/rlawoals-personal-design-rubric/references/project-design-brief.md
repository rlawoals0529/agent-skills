# Reusable project UI design brief

Copy this prompt into a new ChatGPT Chat or coding-agent task. Fill in the brackets.

```text
Use my personal design rubric from the agent-skills repository:
https://github.com/rlawoals0529/agent-skills/tree/main/skills/rlawoals-personal-design-rubric

Project: [name and purpose]
Repo: [URL, if one exists]
Audience: [who uses it]
Primary task: [what should take only a few clicks]
Key data objects: [what the UI must display]
Current visual direction: [Midnight Navy + Muted Slate / another direction / undecided]
Target devices: [desktop and mobile priorities]
Constraints: [stack, no paid tools, accessibility, privacy, branding]

Treat this as product design first, not a generic AI dashboard. Review
existing patterns and actual workflows before adding visual elements.
Use proven principles of high-quality software interfaces: clear
hierarchy, compact navigation, good keyboard workflows, and purposeful
data density. Create original compositions and product-specific interactions.

First give two truly different information architectures and explain
their tradeoffs. Then propose a recommended direction with:
1. Navigation and user journeys
2. Desktop and mobile wireframes
3. Type scale, palette, spacing, density, and design tokens
4. Component inventory and all interaction states
5. Accessibility, asset/license, and responsive requirements
6. Anti-template design critique
7. A functional acceptance and screenshot-review checklist

Avoid generic 3-card landing pages, neon AI gradients, invented metrics,
decorative chatbot heroes, unnecessary modals, and endless CSS overrides.
Keep the actual product usable without AI wherever possible.

Do not make repository edits or deploy until I authorize implementation.
Clearly distinguish observed facts, mock examples, and unverified assumptions.
```

For projects already in development, replace the 'two architectures' request with a focused audit of the actual rendered pages and prioritized before/after improvements.
